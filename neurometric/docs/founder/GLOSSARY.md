## A. Neural interfaces and decoding

| Term | Definition |
|---|---|
| **Action potential (spike)** | The brief (~1 ms) electrical impulse a neuron fires; the basic unit intracortical BCIs record. |
| **Attempted movement / attempted speech** | The user tries to move or speak despite paralysis; motor cortex still generates the corresponding activity, which decoders exploit. |
| **BCI (brain–computer interface)** | A system that measures brain activity and converts it into commands for an external device without using muscles. |
| **BCI inefficiency ("BCI illiteracy")** | The observation that a minority of users cannot reach useful control with a given (usually EEG) BCI paradigm. |
| **Calibration** | Collecting data with known (or assumed) intent to fit or refit a decoder's parameters. |
| **Channel** | One recording electrode (or derived signal) feeding the decoder. |
| **Click decoder / state decoder** | A classifier that detects discrete states (e.g. "click", "rest") from neural activity, often LDA or an HMM with a threshold. |
| **Closed-loop** | The user sees the decoder's output and adjusts; performance reflects user + decoder adaptation together. |
| **CLDA (closed-loop decoder adaptation)** | Updating decoder parameters during closed-loop use, from data collected while the user controls the device. |
| **Cosine tuning** | A neuron's firing rate varies with the cosine of the angle between movement direction and its preferred direction. |
| **Decoder** | The algorithm mapping neural features to control outputs (velocity, click, character, phoneme). |
| **Dial-in time** | Time from first entering a target to completing the selection; long dial-in signals poor fine control. |
| **Drift (non-stationarity)** | Change over minutes to days in the relationship between neural signals and intent, degrading a fixed decoder. |
| **ECoG (electrocorticography)** | Recording field potentials from electrodes on the cortical surface (subdural or epidural). |
| **EEG (electroencephalography)** | Recording summed cortical activity from scalp electrodes; non-invasive, low spatial resolution. |
| **Endovascular BCI** | Electrodes placed inside a blood vessel next to the brain (e.g. Synchron Stentrode in the superior sagittal sinus). |
| **ERD/ERS** | Event-related desynchronisation/synchronisation: power decrease/increase in a frequency band (e.g. mu/beta during motor imagery). |
| **Feature** | A quantity computed from raw signals for decoding (threshold-crossing count, band power, etc.). |
| **High-gamma** | Field-potential power roughly 70–150 Hz, closely tied to local neuronal firing; a key ECoG feature. |
| **HMM (hidden Markov model)** | A probabilistic model of hidden states with transition probabilities; used for click/state decoding. |
| **iBCI (implantable / intracortical BCI)** | A BCI with surgically implanted sensors; "iBCI" in FDA and iBCI-CC usage means implanted BCI. |
| **Intracortical** | Electrodes penetrating the cortex to record spikes and LFPs (Utah array, Neuralink threads, Paradromics). |
| **Kalman filter** | A recursive estimator combining a dynamics model with noisy observations; the standard velocity decoder for BCI cursors. |
| **Language model (in BCI)** | A model of likely word sequences used to correct decoded characters/phonemes; strongly affects WER and WPM. |
| **LDA (linear discriminant analysis)** | A linear classifier often used for EEG and click decoding. |
| **LFP (local field potential)** | Low-frequency extracellular signal reflecting summed synaptic activity near an electrode. |
| **Manifold alignment** | Stabilising a decoder across days by aligning low-dimensional neural activity patterns. |
| **Motor imagery (MI)** | Imagining a movement without performing it; produces SMR changes used by EEG BCIs. |
| **Neural data** | Information generated by measuring nervous-system activity; legally defined in some state privacy laws (e.g. Colorado). |
| **Offline decoding** | Evaluating a decoder on recorded data without the user in the loop; often over-predicts online performance. |
| **P300** | A positive EEG deflection ~300 ms after a rare, attended stimulus; basis of the P300 speller. |
| **Population vector** | The sum of neurons' preferred-direction vectors weighted by their activity; estimates movement direction. |
| **R² (decoding)** | Fraction of variance in intended kinematics explained by the decoder offline; an L2 metric. |
| **ReFIT** | Recalibrated Feedback Intention-Trained Kalman filter: retrains on closed-loop data with intention-corrected velocities. |
| **Recalibration** | Refitting a decoder after performance degrades; costs user time and is a burden outcome. |
| **RNN decoder** | A recurrent neural network decoder capturing non-linear, time-dependent mappings. |
| **Shared control** | Blending decoded user commands with automation (snapping, prediction, autonomous grasp). |
| **SMR (sensorimotor rhythms)** | Mu and beta oscillations over sensorimotor cortex modulated by movement and imagery. |
| **SNR (signal-to-noise ratio)** | Ratio of signal power to noise power; an L1 quality metric. |
| **SSVEP** | Steady-state visually evoked potential: EEG oscillation at the frequency of an attended flickering stimulus. |
| **Stentrode** | Synchron's stent-mounted electrode array delivered via the venous system. |
| **Threshold crossing** | A detected event when the voltage crosses a set threshold; a spike proxy that avoids spike sorting. |
| **Utah array** | Blackrock's 10×10 silicon microelectrode array (96 wired), the classic human intracortical sensor. |
| **Velocity decoder** | A decoder that outputs cursor velocity (integrated to position), the usual choice for BCI cursors. |

## B. Interaction and HCI metrics

| Term | Definition |
|---|---|
| **Achieved bitrate** | log2(N−1) × max(correct − incorrect, 0) / time; assumes each error costs one correction (Nuyujukian et al. 2015). |
| **CCPM / CPM** | Correct characters per minute. |
| **CER / WER / PER** | Character, word and phoneme error rates: edit distance between decoded and intended text divided by its length. |
| **CWPM** | Correct words per minute (used in Neuralink VOICE). |
| **Effective width (We)** | 4.133 × SD of selection endpoints along the task axis; adjusts Fitts' ID for actual accuracy. |
| **False activations per minute** | Unintended selections per minute of active use; the "Midas touch" cost of a selection method. |
| **Fitts' law** | Movement time grows linearly with the index of difficulty, MT = a + b·ID. |
| **Fitts throughput (TP)** | Effective index of difficulty divided by movement time (bits/s), per ISO 9241-411. |
| **ID / IDe** | Index of difficulty log2(D/W + 1); IDe uses effective distance and width. |
| **ISO 9241-411** | ISO technical specification for evaluating input devices, including the multidirectional tapping task. |
| **ITR (Wolpaw)** | Bits per selection from N targets and accuracy P, times selections per minute; assumes equiprobable targets and uniform errors. |
| **KSPC** | Keystrokes per character: input events (including corrections) per transcribed character. |
| **Latency (end-to-end)** | Time from intent or input to visible effect; must be reported with information rate. |
| **Midas touch** | Gaze or neural selection activating things the user only looked at or thought about. |
| **MSD error rate** | Minimum string distance (Levenshtein) between presented and transcribed text, normalised. |
| **Path efficiency** | Straight-line distance divided by actual path length. |
| **Peak vs typical performance** | Best short-session performance (benchmarks) versus routine daily performance; different constructs. |
| **Selection time** | Time to complete a selection with an AT/BCI, including dwell or scan parameters (not "reaction time"). |
| **SPC (scan steps per character)** | The scanning analogue of KSPC. |
| **Target re-entry** | Cursor leaves and re-enters the target before selection; a fine-control error metric. |
| **Total error rate** | (Incorrect-not-fixed + incorrect-fixed) / all characters entered (Soukoreff & MacKenzie 2003). |
| **Webgrid BPS** | Neuralink's grid-selection benchmark: log2(clicks × cells − 1) × net correct per second; a company metric. |
| **WPM** | Words per minute, conventionally (characters − 1) / seconds × 60 / 5. |

## C. Assistive technology, AAC and rehabilitation

| Term | Definition |
|---|---|
| **AAC** | Augmentative and alternative communication: methods supplementing or replacing speech. |
| **ADL / IADL** | Activities of daily living (bathing, eating) / instrumental ADLs (managing money, communication, shopping). |
| **dADL / digital IADL** | Digital activities of daily living (messaging, banking, booking appointments online). |
| **ALS** | Amyotrophic lateral sclerosis, progressive motor neuron disease; a core BCI/AAC population. |
| **ALSFRS-R** | Revised ALS Functional Rating Scale; tracks disease progression, not device benefit. |
| **ARAT** | Action Research Arm Test, upper-limb function test widely used in stroke/SCI. |
| **AT (assistive technology)** | Any device or system that maintains or improves a person's functional capabilities. |
| **AT abandonment** | A user stops using a provided AT device; a real-world outcome. |
| **ATD-PA** | Assistive Technology Device Predisposition Assessment (person–technology match). |
| **Care partner / caregiver** | Person (paid or unpaid) who assists the user; affects set-up, use and outcomes. |
| **COPM** | Canadian Occupational Performance Measure: interview-based ratings of self-chosen goals. |
| **Dwell selection** | Selecting by holding gaze or pointer on a target for a set time. |
| **Eye gaze (eye tracking)** | Estimating point of gaze with cameras to control a pointer. |
| **FMA-UE** | Fugl-Meyer Assessment of the upper extremity (impairment scale, stroke). |
| **GAS** | Goal Attainment Scaling: individual goals scored on a standardized scale. |
| **GRASSP** | Graded Redefined Assessment of Strength, Sensibility and Prehension (cervical SCI hand function). |
| **Head pointer** | Head movement controls the pointer via camera or IR tracking (e.g. Camera Mouse, Apple Head Pointer). |
| **ICF** | WHO International Classification of Functioning, Disability and Health (body, activity, participation, context). |
| **ICF capacity vs performance** | What a person can do in a standard environment vs what they do in their real environment (≈ L4 vs L5). |
| **ISNCSCI** | International Standards for Neurological Classification of SCI (ASIA exam; injury level and completeness). |
| **Locked-in syndrome** | Near-total paralysis with preserved cognition, often only eye movements remaining. |
| **Mouth joystick** | Lip/chin-operated joystick with sip/puff or bite click (e.g. Jouse+). |
| **NASA-TLX** | NASA Task Load Index, six-subscale workload questionnaire; free to use. |
| **PIADS** | Psychosocial Impact of Assistive Devices Scale (competence, adaptability, self-esteem). |
| **QUEST 2.0** | Quebec User Evaluation of Satisfaction with assistive Technology. |
| **SCI** | Spinal cord injury; cervical SCI (C1–C8) causes tetraplegia. |
| **SCIM III** | Spinal Cord Independence Measure, version III. |
| **Section GG** | CMS standardized self-care and mobility items with a 6-level assistance scale (06 independent … 01 dependent). |
| **Sip-and-puff** | Mouth-pressure switch/joystick input. |
| **Switch scanning** | The system highlights options in sequence; the user activates a switch to choose. |
| **SUS** | System Usability Scale, 10-item usability questionnaire. |
| **Switch interface** | Hardware that converts a 3.5 mm accessibility switch into keyboard/mouse/Switch Control input. |
| **Zarit Burden Interview** | Care-partner burden questionnaire (licensed via Mapi Research Trust). |

## D. Psychometrics and statistics

| Term | Definition |
|---|---|
| **Anchor-based method** | Estimating meaningful change by relating score change to an external judgement (e.g. global rating of change). |
| **Bland–Altman limits of agreement** | Mean difference ± 1.96 SD of differences between two methods or occasions. |
| **Ceiling / floor effect** | Many respondents at the top/bottom score (>15% is the usual flag), limiting discrimination and responsiveness. |
| **Classical test theory (CTT)** | Observed score = true score + random error; reliability = true variance / observed variance. |
| **Confounding** | A third variable causes both exposure and outcome, creating a spurious association. |
| **Construct validity** | Evidence a score relates to other measures as theory predicts (hypothesis testing). |
| **Content validity** | Evidence the items/tasks are relevant, comprehensive and comprehensible for the construct and population. |
| **COSMIN** | Consensus-based Standards for the selection of health Measurement INstruments: taxonomy and risk-of-bias tools. |
| **Criterion validity** | Agreement with a gold standard measure of the same construct. |
| **Cronbach's alpha / omega** | Internal-consistency reliability of multi-item scales. |
| **Distribution-based MCID** | Meaningful-change estimates from score spread (0.5 SD, 1 SEM); supportive only. |
| **Effect size (ES) / SRM** | Mean change / baseline SD; standardized response mean = mean change / SD of change. |
| **GRC (global rating of change)** | Patient's rating of how much they changed; common anchor. |
| **ICC** | Intraclass correlation coefficient: share of total variance due to true between-subject differences. |
| **ICC(2,1) / ICC(A,1)** | Two-way random effects, absolute agreement, single measurement; recommended for test–retest of tasks. |
| **ICC(3,1) / ICC(C,1)** | Two-way mixed, consistency; ignores systematic shifts between sessions. |
| **Interpretability** | Ability to assign qualitative meaning to scores and changes (norms, MCID, MDC). |
| **MCID / MID / MIC** | Minimal (clinically) important difference / change: the smallest change patients perceive as beneficial. |
| **MDC / SDC** | Minimal detectable (smallest detectable) change: 1.96 × √2 × SEM for an individual at 95% confidence. |
| **Measurement error** | Systematic and random error in a score not due to true change. |
| **Measurement invariance** | A score means the same thing across groups or modes (e.g. across input devices). |
| **Mixed-effects model** | Regression with fixed and random effects; handles repeated measures and unbalanced data. |
| **Regression to the mean** | Extreme measurements tend to be followed by less extreme ones, mimicking improvement. |
| **Reliability** | Degree to which a measure distinguishes people despite measurement error (test–retest, inter-rater). |
| **Responsiveness** | Ability of a measure to detect change over time in the construct. |
| **Reverse causation** | The outcome causes the presumed exposure (e.g. use causes skill, not skill causes use). |
| **SEM (standard error of measurement)** | Typical size of measurement error in score units (√MS_error or SD√(1−ICC)). |
| **Selection bias** | Distortion because who is studied (or who stays) is related to exposure and outcome. |
| **Spearman–Brown** | Predicts reliability when test length changes. |
| **Test–retest reliability** | Agreement between repeated measurements in stable people. |

## E. Clinical research and regulation

| Term | Definition |
|---|---|
| **510(k)** | FDA premarket notification showing substantial equivalence to a legally marketed predicate device. |
| **21 CFR Part 11** | FDA rules for trustworthy electronic records and signatures (validation, audit trails, access control). |
| **Audit trail** | Secure, time-stamped, computer-generated record of who created, changed or deleted data and when. |
| **Breakthrough Device designation** | FDA programme for devices treating serious conditions with potential for more effective treatment. |
| **ClinRO / ObsRO / PerfO / PRO** | Clinician-reported, observer-reported, performance and patient-reported outcomes: the four COA types. |
| **COA (clinical outcome assessment)** | A measure of how a patient feels, functions or survives. |
| **Composite endpoint** | An endpoint combining several measures into one score or responder definition. |
| **Concept of interest (COI)** | The aspect of health an endpoint aims to measure. |
| **Context of use (COU)** | The specific circumstances (population, purpose, setting) for which a tool is qualified or validated. |
| **De Novo** | FDA classification pathway for novel low-to-moderate-risk devices with no predicate. |
| **Device software function / SaMD** | Software meeting the device definition; software that "interprets or analyzes" device data may qualify. |
| **DHT (digital health technology)** | Hardware/software used remotely to collect clinical-investigation data (FDA Dec 2023 guidance). |
| **EFS (early feasibility study)** | Small first-in-human device study (most current iBCI studies). |
| **eSystems Q&A** | FDA Oct 2024 guidance on electronic systems, records and signatures in clinical investigations. |
| **Endpoint** | A precisely defined variable analysed to answer a trial question (primary, secondary, exploratory). |
| **GCP** | Good Clinical Practice (ICH E6(R3), final Jan 2025; ISO 14155 for devices). |
| **IDE** | Investigational Device Exemption (21 CFR 812) allowing a significant-risk device to be studied in humans. |
| **Intended use** | What the manufacturer says a product is for; largely determines device status. |
| **IRB** | Institutional Review Board approving and overseeing human-subjects research. |
| **MAH (meaningful aspect of health)** | What patients value and want to change; starting point of the MAH → COI → COA framework. |
| **MDDT** | FDA Medical Device Development Tool qualification programme (COAs, biomarkers, nonclinical models). |
| **PFDD guidance series** | FDA Patient-Focused Drug Development guidances 1–4 on patient input and fit-for-purpose COAs (CDRH co-issued #3). |
| **Pivotal study** | The study intended to provide primary evidence of safety and effectiveness for marketing. |
| **PMA** | Premarket Approval, the most stringent FDA pathway, for Class III devices. |
| **Pre-Sub / Q-Submission** | A formal request for FDA feedback before a submission. |
| **Responder analysis** | Percentage of participants whose change exceeds a threshold (often the MCID). |
| **Significant-risk device** | A device whose investigation poses serious risk and needs an FDA-approved IDE (iBCIs generally are). |
| **Source data** | Original records of clinical findings; for DHTs, FDA treats the durable repository as the source location. |
| **Verification vs validation (DHT)** | Verification: the DHT measures its physical parameter accurately and precisely. Validation: it assesses the clinical characteristic in the target population. |
| **513(g)** | A request to FDA for its view on a product's classification and regulatory requirements. |

## F. Payer, coverage and health economics

| Term | Definition |
|---|---|
| **Benefit category** | A statutory Medicare category (e.g. DME, prosthetic device) an item must fit before coverage is considered. |
| **Budget impact analysis** | Estimate of the financial effect of adopting a technology on a specific payer's budget. |
| **CED (Coverage with Evidence Development)** | Medicare coverage conditional on collecting further evidence, often in a registry. |
| **CHEERS 2022** | Reporting standard for health economic evaluations. |
| **Cost-consequence analysis** | Costs shown alongside a disaggregated list of outcomes, without combining them. |
| **Cost-utility analysis / QALY** | Cost per quality-adjusted life year gained; a QALY weights life-years by health utility (0–1). |
| **DME (durable medical equipment)** | Reusable medical equipment for home use (Medicare benefit category; speech-generating devices fall here). |
| **HCPCS Level II** | Medicare codes for supplies, DME and devices (IpsiHand reportedly received one). |
| **HEOR** | Health economics and outcomes research. |
| **HTA** | Health technology assessment (e.g. NICE, ICER). |
| **LCD / NCD** | Local / National Coverage Determination: Medicare coverage policies (e.g. NCD 50.1 speech-generating devices). |
| **Medical necessity** | Payer requirement that a service is reasonable and necessary for diagnosis or treatment, not convenience. |
| **NTAP** | New Technology Add-on Payment for qualifying new inpatient technologies. |
| **Opportunity cost (caregiver time)** | Valuing care time at what the caregiver gives up (e.g. their wage). |
| **RAPID** | Proposed CMS–FDA pathway (2026) to align IDE outcomes with Medicare coverage; not final as of 2026-11-27. |
| **"Reasonable and necessary"** | The Medicare statutory coverage test (§1862(a)(1)(A)). |
| **Replacement cost (caregiver time)** | Valuing care time at the wage of a paid substitute (e.g. home health aide, BLS median $17.21/h May 2025). |
| **RWD / RWE** | Real-world data (collected outside controlled trials) / real-world evidence derived from it. |
| **Speech-generating device (SGD)** | AAC device producing speech; covered as DME under NCD 50.1 (general computing excluded). |
| **TCET** | Transitional Coverage for Emerging Technologies (2024 Medicare pathway; paused for new candidates in 2026). |

## G. Data, privacy and platform

| Term | Definition |
|---|---|
| **BAA (business associate agreement)** | HIPAA contract required when a vendor handles PHI on behalf of a covered entity. |
| **BCI HID** | Apple's protocol letting a BCI present as a HID device to Switch Control (usage page 0x60, not in USB-IF HUT 1.7). |
| **Business associate** | Under HIPAA, an entity creating/receiving/maintaining/transmitting PHI for a covered entity. |
| **Covered entity** | HIPAA-regulated health plan, clearinghouse or provider conducting standard electronic transactions. |
| **Cross-origin isolation** | Browser mode enabling finer timer resolution (5 µs spec floor) via COOP/COEP headers. |
| **DPIA** | Data protection impact assessment of privacy risks before processing. |
| **DUA (data use agreement)** | Contract governing sharing of data (e.g. sponsor usage exports). |
| **HID (human interface device)** | USB/Bluetooth device class for keyboards, mice, switches, eye trackers. |
| **Photodiode / phototransistor** | Light sensor used to timestamp when a stimulus actually appears on screen in latency testing. |
| **PHI** | Protected health information under HIPAA. |
| **Provenance label** | Tag stating whether data are simulated, replayed or live. |
| **Pseudonymisation** | Replacing identifiers with codes; data remain personal data if re-linkable. |
| **Telemetry (consented)** | Opt-in collection of usage durations and counts, never content (NeuroMetric scope rules). |
| **WCAG 2.2** | W3C Web Content Accessibility Guidelines (Recommendation, 12 Dec 2024). |
