# Stage 5 protocol: home-use telemetry feasibility

> **DRAFT. Not submitted. Requires faculty PI and IRB review. No participants enrolled.**
> The full feasibility protocol is `HOME_USE_FEASIBILITY.md`. This file holds the task
> procedures, accommodations and equipment in the same format as the other stage protocols.

## 1. Task procedures at home
- **Weekly home battery** (days 1, 8 and 14): the core battery (`stage1_protocol.md` §4) in the
  browser, with the participant's frozen accessibility profile from setup. About 40–70 min with
  breaks. It may be split across one day by the participant: the battery remembers progress, and
  the split is logged.
- Instructions are on screen. The research assistant joins by phone or video for the first home
  battery (day 1) only if the participant wants. No recording.
- **Daily care-partner diary** (2 min, original, unvalidated): yesterday's minutes helping with
  device setup, troubleshooting, digital tasks, and other ADL/IADL help; a burden item (0–10).
- **Telemetry:** Tier 0 (in-battery) plus, on opt-in only, Tier 1 (Windows activity agent or
  Android UsageStats + AT flags), aggregated on the device to daily totals.

## 2. Accommodations
As `stage4_protocol.md` §6. The home setup is done during the setup visit and photographed
(device only). The diary can be completed by the participant, the care partner, or via AAC.

## 3. Equipment
| Item | Note |
|---|---|
| Participant's own Windows PC or Android device; loaner Windows laptop or Android tablet if needed | Platform matrix verdicts: Windows "technically yes, ethically constrained"; Android "yes, limited" |
| NeuroMetric web battery (university-hosted) | Tier 0 |
| Optional Windows activity agent (signed build, visible indicator, pause/withdraw) or Android app (UsageStats permission granted by the user in Settings) | Tier 1. No keystroke content, screenshots or accessibility-service monitoring (`platform_matrix.md`) |
| Paper or electronic diary | Electronic via the battery app, or paper with a prepaid return envelope |

## 4. Safety
Plan §2.3–2.4. Participants are told not to change their AT settings for the study and to stop
any task that is uncomfortable.
