Demo

Try the battery on your own computer

The interactive demo runs locally, served by the NeuroMetric research app. Nothing is sent anywhere else. It uses synthetic demo data only, and it is not a clinical tool.

If the local app is already running

The demo lives at the /demo path of the local NeuroMetric server. This link works only when this page is served by that app, not when the site is previewed on its own:

Open the demo at /demo

Run it locally

You need Python 3.11 or later and Node.js. From the root of the repository:

  1. Install the Python package:

    cd neurometric
python -m pip install -e .

  2. Build the web app (the server serves web/dist when it exists):

    cd web
npm install
npm run build
cd ..

  3. Optionally create the synthetic demo study (clearly labelled “synthetic data, not patients”), then start the server:

    python -m neurometric.api seed-demo --db demo.db
python -m neurometric.api serve --db demo.db --port 8001

  4. Open http://127.0.0.1:8001/demo in your browser.

Commands may change

The app is under active development. If any command above does not work in your checkout, follow the repository README, which is the authoritative source. Port 8001 is used here so it does not clash with a site preview on port 8000.

For development, the web app can also be run with hot reloading using npm run dev in the web folder.

What the demo is for

The demo is being built alongside the battery. It is intended to show:

  • Battery tasks operated with your own mouse, touch, keyboard, switch (keys) or dwell selection.
  • A simulated degraded input channel, so you can feel how noise, latency or bias change the same task. This is a model, not a reproduction of any BCI.
  • Provisional scores in the browser; authoritative scoring is done in Python from the recorded events.

Please do not use the demo to assess yourself or anyone else. Scores from the demo have no clinical meaning.
